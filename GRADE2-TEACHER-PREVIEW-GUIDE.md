# Little Learning Academy — controlled five-section adult review package

**Status: development-only staging material; not a public/mobile hosted URL and not official approval.**

This guide describes how to inspect the original bilingual English/phonics pilot, adult-only feedback helper, official school source directory and academy brand comparison **without changing the public GitHub Pages site or merging the unreviewed course into `main`**.

## What's inside the ZIP

- **index.html:** friendly review-only landing page with **five routes**.
- **grade2-four-skills.html:** original five-module pilot with 20 core guided skill exercises, 15 additional written letter-pattern checks, and optional reading/writing challenges.
- **grade2-phonics-pathway.html:** eight optional word families and 56 adult-supervised practice stages.
- **grade2-educator-review.html:** adult-generated Accept / Revise / Hold notes, local-only until an adult chooses to copy the text.
- **school-updates.html:** adult-facing Qatar school calendar, Ministry, government, safety and international research references. It reads the bundled **uninitialized** QNA JSON snapshot. It is **NOT** a live emergency feed.
- **academy-brand-review.html:** bilingual proposed-name comparison with four **unverified candidates**, five rating criteria and a locally prepared copy-only adult summary; it is not legal trademark clearance, a domain check, or SEO keyword measurement.
- Their dependent JavaScript, the original `icon.svg`, a copy of the teacher-review checklist, and a manifest.
- The pilot's **Choose Grade** back link is redirected **inside the ZIP only** to the review landing page. The source files on the development branch are not changed by this packaging step.

The expanded package is generated by `node scripts/build-grade2-teacher-preview.cjs`, tested with browser automation and uploaded **as a GitHub Actions artifact**. Downloading an artifact is not equivalent to opening a hosted website.

## For a reviewer with a computer

1. In the repository's **Actions** tab, open a successful **Grade 2 four-skills pilot** run from the review branch and download its `grade2-teacher-preview` artifact if available. GitHub sign-in may be required.
2. Unzip it. Open a terminal in the extracted folder containing `index.html` and run:
   ```
   python3 -m http.server 8765 --bind 127.0.0.1
   ```
3. On that computer, open **http://127.0.0.1:8765/** in Chrome, Edge or Safari. The page works on a local test server without network API calls, paid services, accounts, or uploaded child data.
4. Test modules, phonics, spelling corrections and review notes. The **Review** helper never automatically sends or saves responses; copied text can still contain details a person typed, so inspect it before any further sharing.

**iPhone note:** The localhost address above is for the same computer, **not an iPhone**. Do **not** assume the ZIP opens as a fully working interactive app in iOS Files/Quick Look. An actual iPhone web preview needs a deliberate staging-host decision and verification; do not expose a development server on a workplace, school, hospital, or public network, and do not port-forward a local server to the internet.
