## Review checklist (SEBT technical support / educators)

- [ ] iPhone Safari, iPad and Android: layout, tap targets and loading
- [ ] English and Arabic: phrasing, right-to-left text and qualified Arabic educator approval
- [ ] Accessibility: keyboard focus, VoiceOver/TalkBack and headings
- [ ] Official links: source authenticity, current content, licensing and dated research
- [ ] Exam announcements: distinguish official directory links from specific school notices
- [ ] Emergency safety: no misleading automated alerts; direct parents to official school and government communications
- [ ] Data/privacy: no accounts, tracking, personal student details, microphones or notification permissions
- [ ] Technical: feed freshness and error handling on draft PR #14; the preview's QNA snapshot is deliberately empty
- [ ] Content/pedagogy: distinguish educational research articles from Qatar curriculum requirements
- [ ] Release approval: document reviewer comments and resolve blocking concerns before merging the production module

**Scope isolation:** Preview files are under `review/` on the public main branch so reviewers can access a working, shareable screen without adding the module to the public Academy navigation, enabling news automation, or merging the draft feature. Preview only; no claim of Ministry/school endorsement.
