🛡️ How privacy works • كيف نحمي الخصوصية

This version of Little Learners Academy has no student accounts, advertising, social chat, camera or microphone recording, or application analytics. Learning scores, activity completions, and voice preferences are saved in this browser, on this device.

We do not ask for a child's real name, date of birth, address or contact details. Children should not type personal information into any activity.

Important limits: The app is served by GitHub Pages, so GitHub and network providers may process normal web-request information such as IP addresses and access logs under their own policies. Browser storage can be accessed by anyone using the same unlocked device/browser. A lost or shared device may expose locally saved progress. This page does not offer a password-protected child profile or cloud synchronization.

Source code is publicly visible on GitHub. That does not make the child's on-device learning progress public, and app developers cannot retrieve browser-local progress through GitHub.

📊 Data on this device • بيانات هذا الجهاز

Checking the device's app data…

Only keys belonging to Little Learners Academy (starting with lla-) are counted. Other websites' storage is not touched.

The optional backup is a readable JSON file on your device, not a secret or encrypted file. Keep it private; delete it from Downloads when no longer needed. Export does not upload your data to a server.

🗑️ Erase saved progress • حذف بيانات التقدم

This will erase saved progress, earned stars, completion badges, pronunciation preferences, and feedback stored by this app in this browser. It will not delete the website or affect other devices. It cannot be undone unless you have a backup and manually restore data using a supported future feature.

👨‍👩‍👧 Parent advice • نصائح للأهل

Supervise younger learners, balance screen time with play and reading, and avoid uploading identifying child information. This independent app is not certified by a school or ministry, and formal curriculum and pronunciation approval are still under review.

To remove offline copies of the website itself, use your browser's website-data settings. Erasing progress here does not automatically remove service-worker caches or normal hosting logs.
