🛡️ Child Safety & Privacy السلامة والخصوصية للأطفال

Little Learners Academy is designed for children, with parent/teacher guidance. Safety, privacy, and careful learning design are essential.

🔒 What the current app does

  • No account, password, student name, email, chat room or microphone is required to play the existing activities.
  • Activity progress and stars are stored locally in this browser or installed web app on this device, rather than in a school account.
  • No advertising, third-party analytics, or external AI chat is built into the current activities.
  • The app can cache its own pages, images, and approved recordings for repeat use, including limited offline use.

Important: Local device storage is not a secure vault and can be erased by browser settings or shared with other users of the same device. Do not enter names, medical details, photographs, passwords, or other sensitive information into activity notes. Anyone with access to an unlocked/shared device may see the saved progress.

👨‍👩‍👧 For parents and teachers

  • Use a device protected by a passcode, and keep its browser and operating system updated.
  • Supervise younger children and use age-appropriate screen-time limits.
  • Use only the official GitHub Pages address displayed on the main app; do not download unknown APK files or enter passwords on lookalike sites.
  • Check answers and pronunciation with a qualified teacher; this independent supplementary app is not officially certified by Qatar MOEHE.

🧩 Security measures and limitations

Selected core pages restrict executable scripts to files from the app's own site. The offline service worker limits cached content to packaged app resources. Code updates are checked automatically for a set of unsafe patterns.

These safeguards reduce risk but do not mean the app is impossible to hack. The project is hosted on a public code repository, so all web-page code is visible to others. Never store credentials, API secrets or identifiable student records in the site files or device progress.

Because this is a static site, it does not currently provide a verified child identity, secure server-side student database, or parental-control account system. Such features would require a new architecture, legal review, and independent security testing before launch.

📣 Reporting a security concern

A parent or teacher should stop using an activity if it asks for unexpected personal information, payments, account details, or access to the microphone/camera. Please contact the project owner privately with the page address and a description. Do not post children's personal information or exploit details in a public GitHub issue.

Information describes the current static version of Little Learners Academy, not a guarantee of absolute security. • معلومات خاصة بالنسخة الحالية.
